# Super Reforge

`Super Reforge` 是 MUTUO 制作的 Minecraft 1.21.1 / NeoForge 21.1.244 数据驱动重铸模组。

当前仓库正在按照 [设计规格](docs/superpowers/specs/2026-08-01-super-reforge-design.md) 和
[实施计划](docs/superpowers/plans/2026-08-01-super-reforge-implementation.md) 开发。

## 构建环境

- Java 21
- Minecraft 1.21.1
- NeoForge 21.1.244

Windows 使用 `gradlew.bat build`，Linux/macOS 使用 `./gradlew build`。

代码采用 `LGPL-3.0-or-later`。最终资源署名与参考边界会记录在 `CREDITS.md`。

## 3. 模组主页正文

主页正文控制在适合快速阅读的长度，包含以下内容：

1. 开篇简介：说明本模组为 Minecraft 1.21.1 / NeoForge 的数据驱动词条重铸模组，可处理武器以及安装 Curios 后识别的饰品。
2. 基本玩法：玩家使用熔核锻台，将一个目标物品和符合定义的重铸媒介放入槽位，在确认材料、经验和候选概率后开始重铸。
3. 主要功能：列出动态前缀、Attribute 效果、八个默认品质、三类默认词条池、三种媒介、服务端概率预览、数据包与 KubeJS 自定义、服务器配置及进度阶段。
4. 依赖关系：NeoForge 为必需加载器；Curios 和 KubeJS 均为可选依赖，未安装时不影响核心武器重铸和数据包功能。
5. 数据与兼容说明：本模组不注册自有 Attribute，可引用 Minecraft 或其他已安装模组注册的 Attribute 资源 ID。
6. 教程入口：主页末尾引导读者查看独立教程，但主页本身仍提供完整的基础介绍，不以站外链接代替正文。

## 4. 独立教程结构

### 4.1 安装条件

- Minecraft 1.21.1。
- Java 21。
- NeoForge 21.1.244 或同 Minecraft 版本的后续兼容构建。
- 客户端和服务端均安装 Super Reforge。
- Curios 9.x 只在需要通用饰品支持时安装。
- KubeJS 2101 只在需要脚本定义、谓词或全服阶段 API 时安装。

### 4.2 基础重铸流程

1. 合成并放置熔核锻台。
2. 在目标槽放入一个可重铸物品。
3. 在媒介槽放入能够匹配该物品类型的重铸媒介。
4. 阅读锻造日志中的材料、经验和候选概率。
5. 点击开始重铸，等待默认约 20 tick 的锻造动画完成。
6. 取出带有新前缀及 Attribute 效果的物品。

教程需要说明目标槽只接受数量为 1 的物品；重铸在服务端完成并扣除材料与经验；默认不允许在存在其他候选时重复抽到当前词条。

### 4.3 默认内容与概率

- 八个默认品质：粗糙、普通、精良、稀有、史诗、传说、神话、神圣。
- 七个默认物品类型：剑、斧、弓、弩、三叉戟、重锤和 Curios 饰品。
- 近战、远程和 Curios 各八个默认词条，共 24 个示例定义。
- 普通、精炼和至尊三种重铸媒介分别提供不同品质范围。
- 等级与等级内词条均使用相对权重；实际概率为当前有效候选的权重除以同一层级有效权重总和。

### 4.4 配置与自定义

教程分别说明：

- `serverconfig/superreforge-server.toml` 中的经验开关、等级/点数支付模式、自动首词条、提示行、动画时长、创造模式付款和失效定义策略。
- 数据包的四类目录：`levels`、`item_types`、`modifiers`、`catalysts`。
- ItemSelector 可按物品 ID、物品标签、Curios 通用识别或 KubeJS 谓词匹配。
- Attribute effect 可使用固定值或范围值，选择三种原版运算方式及主手、副手、护甲或 `curios:any` 槽位。
- KubeJS 定义必须位于 `server_scripts`，其同 ID 定义覆盖数据包层。

### 4.5 添加、覆盖与删除案例

教程提供一组相互关联的最小案例，而不是复制全部 API 文档：

1. 使用数据包添加一个自定义等级、物品类型、词条和媒介。
2. 使用 KubeJS 以相同资源 ID 覆盖该词条，展示名称、权重或 Attribute 范围的修改。
3. 删除 KubeJS 中的同 ID 定义并成功重载，使数据包中的原定义重新生效。
4. 同时删除脚本与数据包定义后，解释该定义从活动快照消失。
5. 说明已有物品的处理：`REMOVE` 会移除已不存在的词条数据；`KEEP_INACTIVE` 会保留 ID 和种子，但在同 ID 定义恢复前不提供名称或 Attribute 效果。

正式 JSON 只能使用 `.json`；带注释的 `.jsonc` 只用于阅读，不直接装入游戏。数据包修改后使用 `/reload`，KubeJS 脚本必须在完整校验成功后才会原子替换当前脚本层。

### 4.6 常见问题

- 目标槽为空或目标堆叠数量不为 1。
- 目标物品未命中任何物品类型。
- 媒介不匹配、数量不足或没有有效候选。
- 玩家经验不足。
- 客户端词条定义尚未同步完成。
- 熔核锻台正在执行上一轮重铸。
- 数据包或脚本定义解析、引用或交叉校验失败。

每个问题只给出可操作的检查方向，不臆测未经验证的故障原因。

## 主页介绍

Super Reforge 是 MUTUO 制作的 Minecraft 1.21.1 / NeoForge 重铸模组，围绕装备词条、品质和重铸媒介提供一套可由数据包定义的重铸流程。它面向想为原版或其他模组已注册 Attribute 配置装备词条的整合包作者、服务器管理者和玩家。

玩家可通过熔核锻台进行重铸：放入恰好一个目标物品与匹配的重铸媒介后，在锻造日志中查看由服务端判定的成本与概率预览，再开始锻造。默认动画为约 20 tick；经验成本可由服务器关闭，或按等级（LEVELS）和经验点（POINTS）支付。

重铸结果会作为物品的动态显示前缀保存，铁砧重命名不会把此前缀写死或丢失。一个词条可包含多个固定值或范围随机的 Attribute，分别设置运算方式与装备槽位；模组不注册自定义 Attribute，而是使用游戏或其他模组已注册的资源 ID。

词条、品质、物品类型和媒介均可由数据包定义，并会在资源 reload 时经过交叉校验后更新。Curios 与 KubeJS 均为可选兼容：安装 Curios 可使用饰品相关能力，安装 KubeJS 可在 `server_scripts` 中定义内容和全服阶段；二者均未安装时，原版武器和数据包重铸功能仍可运行。

## 主要功能

### 熔核锻台与服务器判定

内置熔核锻台、锻造日志界面、服务端权威的概率预览，以及默认约 20 tick 的锻造动画。重铸开始前会检查目标物品、媒介和候选词条；锻造日志用于查看本次成本与概率信息。

### 品质、词条与相对权重

默认提供 8 个品质等级：`worn`、`common`、`fine`、`rare`、`epic`、`legendary`、`mythic`、`divine`，以及近战、远程和 Curios 三组共 24 条示例词条。媒介与词条的权重使用相对值计算，系统按 `weight / sum(weight)` 自动归一化；默认提供普通、精炼、至高三种重铸石。

### 动态前缀与 Attribute

重铸为物品动态显示前缀，铁砧改名不会使前缀丢失或固定到名称中。词条可组合多个固定值或范围随机的 Attribute，并为每个 effect 指定运算方式和主副手、护甲或 `curios:any` 槽位；范围值会按物品保存的种子稳定确定。

### 多物品类型合并

默认物品类型包括 `sword`、`axe`、`bow`、`crossbow`、`trident`、`mace`、`curio`。当目标命中多个物品类型时，系统合并对应词条池，并按词条 ID 去重，使同一词条只参与一次候选。

### 数据包与 KubeJS 自定义

数据包在资源 reload 时读取 `levels`、`item_types`、`modifiers`、`catalysts` 四类定义；四类内容通过交叉校验后才会发布新的快照。正式数据包应使用 `.json`，`.jsonc` 仅适合阅读和抄写。安装 KubeJS 后，可在 `server_scripts` 中通过 `SuperReforge` 添加四类定义、谓词和全服阶段；同 ID 的脚本定义覆盖数据包定义。

### Curios 可选兼容

Curios 是双端可选依赖。安装后，数据包可用 `curios:any` 匹配被 Curios 识别的饰品，并把相应 Attribute 应用到非外观饰品槽；未安装时，这些 Curios 专用匹配不会命中。

### 服务器配置与进度阶段

服务器配置位于世界目录的 `serverconfig/superreforge-server.toml`，由服务器决定，客户端本地配置不覆盖其规则。KubeJS 的全服阶段状态保存在服务器世界数据中；多个阶段同时激活时，只采用优先级最高的阶段来影响媒介与经验成本。

## 安装与依赖

需要 Minecraft 1.21.1 与 NeoForge 21.1.244，或适用于 Minecraft 1.21.1 的后续兼容 NeoForge 构建；NeoForge 与本模组均需在客户端和服务端安装。Curios（配置版本 `9.5.1+1.21.1`，依赖范围 `[9,)`）和 KubeJS（配置版本 `2101.7.2-build.372`，依赖范围 `[2101,)`）为双端可选依赖：它们分别启用饰品兼容与脚本 API，不安装不会阻止原版武器与数据包重铸功能运行。

## 使用教程

基础流程可概括为六步：安装匹配版本的 NeoForge 并在客户端、服务端放入模组；进入世界后获取或合成熔核锻台与重铸石；准备一个符合定义的目标物品；在锻台放入该物品和一种匹配媒介；在锻造日志核对成本与概率预览后开始重铸；等待锻造完成并查看物品的前缀与 Attribute 结果。数据包、KubeJS 和服务器配置的具体字段与示例请参阅 [MCMOD_TUTORIAL.md](MCMOD_TUTORIAL.md)。
